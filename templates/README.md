# templates

Empty templates for every file in a venture run, matching `skills/file-schemas/SKILL.md`.
`ideas/idea-id/` stands for `ideas/<idea-id>/`. Round-2 files (`forge-v2.md`, `economics-v2.md`,
`prosecution-*-v2.md`, `audit-v2.md`, `verdict-v2.md`) use the same templates as their v1 counterparts with `version: 2`.
`04-screen-pivot<k>.md` uses the `04-screen.md` template.
